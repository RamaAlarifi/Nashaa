# Official Nashaa assets

These are unmodified SVG exports from the supplied `nashaa-logo-kit.zip` (the original project materials, `logo_kit_v2`). `Logo.tsx` uses the bilingual horizontal artwork, including its outlined Arabic wordmark. Color and reversed variants, versions with/without the tagline, standalone marks, favicon and app icon are included.

Full color appears on white/sand, reversed artwork on navy. The component reserves clear space, uses a 152px horizontal logo without tagline, and 240px minimum width with tagline. Standalone icons have a 24px minimum. Do not stretch, rotate, recolor or recreate the artwork. The English tagline is "From Idea to Opportunity".
